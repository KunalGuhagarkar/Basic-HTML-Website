# Basic-HTML-Website

A simple multi-page portfolio website built using **HTML only**, with a focus on semantic structure, accessibility, and basic SEO metadata.

## Project Overview

The goal of this project is to learn how to structure a website using HTML without adding CSS or JavaScript. The project focuses on understanding the different structural elements of a website, including headers, navigation, main content, articles, forms, and footers.

The website contains four pages:

* Homepage
* Projects
* Articles
* Contact

Each page includes a consistent navigation bar linking to all other pages. 

## Features

* Multi-page HTML website
* Semantic HTML structure
* Consistent navigation across all pages
* Homepage with developer introduction
* Projects page
* Articles page
* Contact form
* Responsive viewport meta tag
* SEO description meta tag
* Author meta tag
* No CSS
* No JavaScript

The pages use metadata such as `description`, `author`, and `viewport` inside the `<head>`.
